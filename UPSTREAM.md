# Optional upstream distributions

These projects and services have their own installation channels. Choose the specific capability you need and read the terms for the version you install. The collection's profile helper only installs directories in this repository.

| Capability | Where to get it | Check after installation |
| --- | --- | --- |
| Framework-specific video production | The [Remotion skills repository](https://github.com/remotion-dev/skills) documents its supported installation and versioned guidance. | Open a disposable composition and render one local frame with the installed project version. |
| React project diagnostics | Review the [React Doctor distribution and terms](https://github.com/millionco/react-doctor). | Run its documented check on an existing sample project and inspect the reported source location. |
| Word, spreadsheet, presentation and PDF workflows | Read the [Anthropic skills collection](https://github.com/anthropics/skills) and each skill's own terms. Runtime features are available through the host's supported setup. | Open a scratch document and verify the intended edit in its normal viewer. |
| Phase-based project planning | Use the supported instructions from [Get Shit Done](https://github.com/gsd-build/get-shit-done). | In an isolated project, verify that the selected planning command is discoverable. |
| Full board analysis toolkit | See [KiCad Happy](https://github.com/aklofas/kicad-happy) for its original scripts and dependencies. | Compare a known connector's pin mapping with the native schematic viewer. |
| Full shot-analysis application | [REA Video](https://github.com/JuneYaooo/rea-video) maintains its CLI and installation instructions. | Inspect a short clip you own and check reported cut times against the actual footage. |
| Document compilation into a wiki | The [upstream knowledge-base workflow](https://github.com/LCccode/Karpathy-wiki-graph/tree/1efa4fe605ac457a61972293976d7d94bda04587) documents its separate application. | Use staged copies of two synthetic source documents in a disposable knowledge base. |
| Host-specific integrations and plugins | Use the plugin catalog and installer in the host that supplies the integration. | Confirm the tool appears in a fresh session and test with disposable inputs in that service. |

The portable workflows in this repository can be used independently of these distributions unless a skill explicitly names a dependency.
