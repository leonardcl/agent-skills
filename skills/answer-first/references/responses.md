# Worked responses

**Status.** “The import passed all six fixtures. The overnight run is still pending.” If the user only asks whether the import passed, this can be the whole response.

**Review.** “Hold the release until a clean installation can reopen saved work. Existing installations passed, but a new profile lost the first saved entry. I reproduced it on the published build. The mobile path remains untested.” Preserving the failed path and the coverage gap matters more than fitting a fixed length.

**One owner decision.** “Both windows satisfy the cutoff. Tuesday gives support two extra days, while Thursday avoids the training session. Which window should I reserve?” Ask only when the choice actually blocks the authorized work.

When performing ordered actions, give their sequence as a numbered list. For independent findings, use paragraphs or bullets. Do not invent an estimate to make a request seem more manageable.
