# Brand voice

Read only the writing samples and owner rules selected for this brand. Assign source IDs. Record observable choices with examples and scope, including contrary instances. A pattern found in one announcement is tentative. An owner rule can outweigh a common habit; preserve the distinction in the profile. On a held-out brief, make a fact list first, adapt rhythm and the action for the target channel, then check every name, quantity, date and exception. Start a separate profile when the brand or language changes. See the profile schema for fields and a worked comparison.

Use the [voice profile schema](references/voice-profile.md) for extraction, exceptions and held-out drafts. Audience copy drafts from a brief, Copy edit revises existing prose and Editorial constraints resolves conflicting house rules. Use the named profile as evidence when applying those workflows.

## Try it

One sample brand uses short notices and verb-first instructions. A second brand uses full-sentence invitations. Adapt the same confirmed event facts for an email and a sign.

**Expected result.** The email and sign preserve the confirmed facts and differ in an evidenced channel-specific way. A different brand draws only on its own selected material.

**Limit.** Personal profiles stay in an explicitly selected project destination. No accounts, messages or social history are read automatically.
