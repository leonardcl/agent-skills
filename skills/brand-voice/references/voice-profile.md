# Voice profile

Create a new profile for the named brand and language. Include the intended audience, channel, purpose, owner and selected sample IDs. Store it only in the destination the user authorized. When the brief changes audience or channel, use only traits whose scope still fits.

| Field | What to capture |
| --- | --- |
| Source set and confidence | IDs, formats, dates if supplied, range and gaps. Three copies of one announcement count as one sample. |
| Rhythm and compression | Where short clauses help and when the author expands an explanation. |
| Capitalization, asides and questions | Specific punctuation or casing tied to a sample. Note when quotations or proper names dictate it. |
| Claims and language | How the author introduces evidence, uncertainty and specialized terms. Preserve locale-specific register. |
| Preferred phrasing and exceptions | Each trait gets a supporting sample ID, its scope and a counterexample if one exists. |
| Owner rules and exclusions | Quote only the selected short rule with its scope. Absence of a pattern in a few samples is weak evidence for forbidding it. |
| Call to action and channel | Compare a sign, message or long-form piece only when the sample set supports the comparison. Mark an extrapolation as provisional. |

For an invented garden club, two signs start with “Bring” and “Meet.” An email opens with a full invitation and explains where to enter. Derive a verb-first tendency for its signs, preserving the longer email as an exception. If the owner explicitly requires the full location name, that applies even when brevity would omit it. For a new event, verify time and location against the brief after adapting both channels. Start a separate profile for a second brand.

Adapted from ECC’s voice-profile schema. This schema uses selected samples, distinguishes observed habits from owner rules and carries no example author's persona.
