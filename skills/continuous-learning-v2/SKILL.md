# Continuous learning v2

Start from selected observations cleared for the named project. Record a stable observation ID, source type, bounded redacted evidence and whether it supports or contradicts a candidate. Repeated evidence from the same event counts once. Keep counterexamples visible and put a disputed lesson back in review. A person can correct the wording, narrow applicability or retire the candidate. Apply an accepted lesson only in its recorded scope. For broader promotion, obtain the new audience, wording, destination and authorization. Transfer the reviewed general rule alone. Keep evidence and project identifiers local.

For a manual, local lifecycle with a duplicate and a contradiction, follow the [ledger example](references/ledger.md).

## Try it

In a disposable project, one export lost its heading. Two reports describe the same export. A later export preserves its heading under a different setting.

**Expected result.** The duplicate counts once, the contrary observation remains visible and another project cannot inherit the candidate. Retirement and broader promotion are explicit decisions.

**Limit.** The local edition has no hooks, transcript ingestion, observer, host memory write or background service.
