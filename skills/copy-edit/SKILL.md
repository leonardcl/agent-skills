# Copy edit

Revise audience-facing copy while preserving the author's voice and supporting facts.

## Workflow

1. Find the visitor's actual decision and the source facts about the exhibit.
2. Replace unsupported descriptions with one concrete detail. Preserve proper names, registration terms and accessibility information.
3. Read the invitation aloud, check it against the supplied source, and test the action text in context.

## Try it

A museum invitation describes an exhibit as revolutionary without saying what visitors see.

**Expected result.** A revised invitation that tells readers what they can see and how to attend.

Replace a superlative with a visible exhibit detail supplied by the curator. Leave the detail blank in the draft when nobody has confirmed it.

**Limit.** Factual gaps need confirmation before publication.
