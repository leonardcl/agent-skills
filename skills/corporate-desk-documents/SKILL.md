# Corporate desk documents

Choose the file format the recipient can edit. Work on a copy, preserve source values and styles, and open the result in a local viewer. Verify the structure as well as what the recipient can see. Use a capable installed editor or library for the actual format.

Choose the [task procedure](references/workflows.md) matching the requested outcome. Available topics include canvas-design, doc-coauthoring, docx, file-organizer.

## Try it

Turn a two-row agenda into a one-page document and a two-slide briefing, using the supplied meeting title.

**Expected result.** The editable title and both agenda rows survive reopening. The exported pages have no clipped text.

**Limit.** Rendering and format fidelity depend on the recipient’s viewer, fonts and installed format libraries.
