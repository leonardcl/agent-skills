# Corporate desk documents workflows

## canvas-design

Use the actual message, audience and final canvas size to choose hierarchy. Make a print or screen layout from original shapes and cleared assets. Inspect the exported artifact at its intended size.

## doc-coauthoring

Agree on the reader, decision and source facts. Draft an outline, resolve uncertain sections with the author, and ask a cold reader to locate the decision and its supporting evidence.

## docx

In a local editor, apply semantic headings and native tables, save an editable DOCX and reopen it. Compare heading order and table contents with the brief, then inspect pagination in the target viewer.

## file-organizer

Inventory a disposable folder, suggest destinations and identify name collisions before moving anything. Preserve an old-to-new manifest and verify counts and sample contents after an approved move.

## memory-management

Use only the user-selected project record. Locate the existing decision heading, append the new evidence and link once. Reopen the destination and preserve prior contrary observations.

## pdf

Export from an editable source or examine a supplied sample PDF. Reconcile the page count, extracted text and page images. Mark scanned or inaccessible text separately from missing content.

## pptx

Put one decision or comparison on each editable slide. Check title order, referenced figures and overflow in slideshow view and in the exported pages.

## theme-factory

Derive a reusable type, spacing and color set from supplied design constraints. Apply it to a long heading, dense table and chart, then inspect readability in the intended export.

## xlsx

Keep source inputs separate from formulas, label units and identify the target calculation. Recalculate in a spreadsheet engine and change one input to verify the expected dependent total.
