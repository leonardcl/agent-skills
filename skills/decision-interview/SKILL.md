# Decision interview

Resolve consequential design questions through a focused interview.

## Workflow

1. Inspect the current behavior first. List only decisions the existing material cannot answer.
2. Ask the highest-impact question with a concrete conflict example and an implementable default.
3. Use each answer to narrow the next question. Record settled terms and show how the example resolves.

## Try it

A reading list should support offline edits, but conflict handling is undecided.

**Expected result.** A decision record distinguishes agreed behavior, unresolved conflicts and assumptions.

Ask what a reader should see if two devices edit the same title offline. Once the answer is retained alongside the example, a later implementation can be checked against it.

**Limit.** An unanswered question stays open when the choice belongs to the user.
