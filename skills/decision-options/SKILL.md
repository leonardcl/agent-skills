# Decision options

Compare strategic options against explicit goals, evidence and constraints.

## Workflow

1. State the decision and include keeping the current arrangement. Identify the constraint that actually binds, such as room availability.
2. Compare the options under the same criteria. Mark observed attendance separately from expected attendance.
3. Recommend an option, give the assumption that could reverse it and suggest the cheapest way to test that assumption.

## Try it

A reading group must choose between one long workshop and two shorter sessions.

**Expected result.** A decision brief with comparable alternatives, supporting evidence and a reversal condition.

A second workshop date is feasible only after the second room slot is secured. Compare the single-slot option against that dependency and identify what confirmation would change the recommendation.

**Limit.** Financial projections require supplied figures and assumptions.

## Reversal test

If the only available room has one free evening, a two-evening plan depends on securing a second venue. If a second evening is confirmed, compare attendance evidence before committing. Write the assumption this plainly so the decision can be revisited when new information arrives.
