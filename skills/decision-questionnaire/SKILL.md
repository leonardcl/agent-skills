# Decision questionnaire

Turn unresolved questions into a form a stakeholder can answer asynchronously.

Use this workflow when the user selects it or specifically asks for this deliverable.

## Workflow

1. Group open decisions by dependency. Supply a short concrete example for each.
2. Write mutually exclusive choices where possible, allow free text and state what each answer affects.
3. Check that a respondent can answer using the material in the form and that each answer changes a real decision.

## Try it

Two contributors disagree about labels and sorting for a book index.

**Expected result.** A short questionnaire with context, answer space and an explicit handling of unanswered items.

A question about sorting should show two actual orders, specify how ties resolve and say whether the user's answer affects existing lists.

**Limit.** Collect only information needed to settle the stated decisions.
