# Design alternatives

Create comparable design alternatives for a defined decision.

Use this workflow when the user selects it or specifically asks for this deliverable.

## Workflow

1. Fix the user task, data and device size. Identify the design axis each variant changes.
2. Produce genuinely different alternatives using the same real-length content and interaction requirements.
3. Walk the same find-and-select task in each alternative and document when each wins.

## Try it

Compare a grouped list with a compact table for browsing a reading list.

**Expected result.** Two alternatives with comparable evidence and a reason to select one for the stated task.

Use the same title and date columns in the grouped and tabular versions. A version containing extra metadata would make the selection task incomparable.

**Limit.** A preferred appearance alone does not establish task performance.
