# Design quality review

Review a design against its actual audience, purpose and visible evidence.

## Workflow

1. Identify the reader's primary task and the element that should receive first attention.
2. Inspect each repeated device in context. Keep it when it aids grouping or recognition. Mark decoration that competes with navigation.
3. Describe one concrete revision and compare the original and revised views at the same size.

## Try it

A library catalog landing page repeats its heading on every card.

**Expected result.** An annotated finding ties the repetitive heading to a real navigation problem and shows a clearer version.

A repeated heading earns its space when it labels a distinct group. If all cards repeat the page title, replace it with the unique topic and test whether readers can locate one entry.

**Limit.** Visual preferences need the brief or a usability observation to justify a finding.
