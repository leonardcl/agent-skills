# Draft from fragments

Turn a collection of observations into a coherent first draft.

Use this workflow when the user selects it or specifically asks for this deliverable.

## Workflow

1. Mark which fragments are direct observations and which need a source. Keep a working copy of the original phrasing.
2. Choose a reader question and arrange the supported observations in the order that answers it.
3. Read the draft through once with the notes beside it. Remove an unsupported explanation or turn it into an explicit question.

## Try it

Use three observations from a library visit to explain how the return shelf works.

**Expected result.** A draft with a clear through-line and a separate list of facts that still need checking.

“The shelf emptied before lunch” supports a time-bound observation. “Readers prefer the shelf” needs evidence about their choice. The first observation can carry the paragraph by itself.

**Limit.** Preserve quotations exactly and identify invented examples.
