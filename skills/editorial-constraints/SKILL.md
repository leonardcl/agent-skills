# Editorial constraints

Apply project-specific editorial decisions and document justified exceptions.

## Workflow

1. Collect the current project brief, terminology list and intended audience. Identify which rule applies to the disputed term.
2. Preserve mandatory terminology and explain its meaning on first use. Resolve remaining conflicts using the more specific instruction.
3. Check the final wording against the claim source and identify any unresolved exception.

## Try it

A guide uses an approved technical term that a general style sheet discourages.

**Expected result.** A revision that uses the required term consistently and records the rule that governs it.

Keep the approved formal term in the first sentence and define it in ordinary language. The project glossary settles the spelling while the audience determines the explanation.

**Limit.** A style rule from another project has no authority here.
