# Evidence notes

Find the relevant note in the notebook the user selected. Read its surrounding section before editing.

1. Identify the question a future reader will ask. Locate the decision or observation that answers it.
2. Record the date, scope and source together. If the user supplied an observation directly, attribute it to their report.
3. For a changed decision, keep the earlier entry and date the new choice. When the evidence leaves a question open, say what observation could settle it.
4. Link the entry from a relevant existing note. Reopen the link and verify that it leads to the intended passage.
5. Tell the user where the entry lives and what changed. Use their existing folder and link conventions.

## Worked example

Three of four participants found the receipt link in checkout layout B without a hint. Nobody measured task time. Save the observed count and prototype version with the session notes. Leave checkout speed as an open question.

**Expected result.** A linked observation attributes the count to the session report and leaves task time open.

**Limit.** An observation about four participants cannot establish a population-wide rate.
