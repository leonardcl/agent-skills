# Interface typography

Choose and check typography for real interface content.

## Workflow

1. Collect representative short, long and multilingual strings. Identify the hierarchy and available width.
2. Set type size, weight, line-height and wrapping as a system. Test enlarged text and font fallback.
3. Inspect clipping, misleading truncation and punctuation in context, then record the relevant tokens.

## Try it

Long chapter titles truncate while short ones appear balanced.

**Expected result.** Examples show title and metadata hierarchy with long text still recoverable.

Measure a long title at increased text size. If truncation is necessary, give the reader a reachable way to see the full title.

**Limit.** Font availability and shaping behavior vary by platform.
