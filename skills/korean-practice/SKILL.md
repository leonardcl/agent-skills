# Korean practice

Teach a Korean expression through register, examples and a transfer exercise.

## Workflow

1. Establish the situation and speech level. Give the Hangul form first and explain the specific meaning in context.
2. Contrast two short sentences that change only the location or object. Ask the learner to produce one new sentence.
3. Correct the smallest issue, explain why and check the same pattern with a fresh noun.

## Try it

Explain when to use 있어요 to describe an object in a room.

**Expected result.** A natural example, a learner prompt and a check that distinguishes location from possession.

In 가방 안에 펜이 있어요, 에 marks the location and 펜이 identifies what is there. Change the location first and then the noun to check each part separately.

**Limit.** Several natural expressions may fit. Register depends on the relationship and setting.

## Practice pair

책상 위에 책이 있어요. There is a book on the desk. 가방 안에 책이 있어요. There is a book in the bag. Ask the learner to say that there is a pen in the bag. One suitable answer is 가방 안에 펜이 있어요. Here 에 marks the location of the object. Check the location and object independently.
