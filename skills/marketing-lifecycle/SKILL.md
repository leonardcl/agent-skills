# Marketing lifecycle

Model the user's current state, entry event, intended next action and exit or suppression condition. Trace one returning user through the sequence, including a duplicate event. Prepare drafts for review and measure outcomes at the user level.

Choose the [task procedure](references/workflows.md) matching the requested outcome. Available topics include churn-prevention, cold-email, emails, onboarding.

## Try it

A trial user finishes setup, but receives another reminder for the same task in the sample sequence.

**Expected result.** The corrected lifecycle map suppresses the reminder after completion and defines a measurable activation event.

**Limit.** No message delivery, customer-system integration or account access is included.
