# Marketing lifecycle workflows

## churn-prevention

Define churn separately for accounts, seats and revenue. Compare cohorts at the same age, distinguish voluntary cancellation from payment failure and match an intervention to the observed cause.

## cold-email

Draft a single fictional message from an approved product fact and stated recipient role. Explain relevance without inferred personal details, give a low-friction response option and mark it for internal review only.

## emails

Give every email draft a trigger, recipient state, useful content and stop condition. Walk one sample subscriber through the sequence and suppress reminders after the target action.

## onboarding

Choose the first user action that demonstrates value. Trace the path from arrival to that action, remove a dependency or provide recovery, and measure completion among genuinely eligible accounts.

## prospecting

Score a fictional account list against explicit organization-level fit criteria. Explain each inclusion from supplied attributes and keep missing information visible. Return an internal shortlist only.

## referrals

Map eligibility, invitation state, acceptance and reward conditions as an offline state table. Test duplicate acceptance and a self-referral case, then reconcile unique qualified outcomes. See the [detailed guidance](referrals-detail.md).

## revops

Define stage entry and exit, stable account identity and owner handoff. Reconcile beginning pipeline, entries, exits and ending pipeline. Flag duplicate opportunities and impossible backward timestamps. See the [detailed guidance](revops-detail.md).

## sales-enablement

Translate a buyer objection into an accurate response, supporting evidence and next question. Draft a local one-pager and test it against a case the product does not support. See the [detailed guidance](sales-enablement-detail.md).

## sms

Draft a fictional short message using only authorized facts and an illustrative consent state. Model opt-out before any follow-up and calculate the number of messages the suppression rule would prevent. No delivery action is part of the exercise.
