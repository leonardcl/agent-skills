# Plain language edit

Edit technical prose while preserving its claims, scope and voice.

## Workflow

1. Mark the actor, action and evidence for each factual claim. Preserve uncertainty and exact product terms.
2. Replace generic claims with observable changes and shorten sentences that hide the action.
3. Compare the revision with the source line by line and flag any claim that still needs verification.

## Try it

Rewrite a release note that promises a faster search without a measurement.

**Expected result.** A concise release note with the unsupported speed claim removed or qualified.

Replace a speed claim without timing data with the observable change, such as “Search now includes chapter titles.” Ask for the measurement before promising a faster result.

**Limit.** Text alone cannot establish measured performance.
