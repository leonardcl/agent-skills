# Requirements response

Draft a proposal by mapping each requirement to verifiable evidence.

## Workflow

1. Extract requirements into a matrix with the source wording, response location and evidence owner.
2. Draft the work, deliverables, schedule and acceptance criteria from the matrix. Separate assumptions from commitments.
3. Walk every mandatory row back to a paragraph. Flag missing credentials, costs or dates for the owner.

## Try it

A reading club asks for a two-session workshop with accessible handouts.

**Expected result.** A proposal draft and a coverage matrix showing what remains unconfirmed.

An accessible handout commitment needs an agreed format and a delivery point. A line saying “we value accessibility” answers neither part of the requirement.

**Limit.** A proposal cannot commit an unconfirmed resource or invent prior work.

## Requirements matrix

| Requirement | Response in draft | Evidence or open item | Acceptance |
| --- | --- | --- | --- |
| Two sessions | Delivery schedule | Confirm facilitator availability | Two distinct session slots listed |
| Accessible handouts | Materials | Confirm the requested format | Reader receives the agreed format before the session |

Replace these fictional rows with the requester's own wording and section references.
