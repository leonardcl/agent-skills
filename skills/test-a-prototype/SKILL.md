# Test a prototype

Build the smallest prototype that answers one product question.

## Workflow

1. State the hypothesis, decision threshold and evidence a prototype can produce.
2. Build the relevant path using sample content. Give participants a neutral task and record where they first look.
3. Summarize observations and their effect on the decision. Preserve the prototype separately from production code.

## Try it

Can readers locate the next chapter without opening the index?

**Expected result.** A runnable example, a task script and a decision tied to observed behavior.

Use the same next-chapter task in both layouts without naming the control. Record the first action before giving a hint, then distinguish success before and after prompting.

**Limit.** A prototype demonstrates a path. Performance and demand need separate evidence.
