# Visual direction

This edition adapts Anthropic’s frontend design guidance with a reading-index example and a rendered keyboard and layout check. See the [origin statement](ORIGIN.md).

## Workflow

Identify the decision a visitor makes first. Lay out actual entries, including the longest label and any fields visitors compare. Preserve the brief's fixed choices. Where it leaves room, choose a composition that makes the decision easier. An index for choosing among translations might align the language and translator in rows. A reader resuming one text might need the last-opened title above the list.

Give the chosen composition one recognizable cue drawn from the material. Try it on a second entry. A spine-like rule can group editions of a book, but a rule on every line obscures the groups. Set type, contrast and spacing so someone can distinguish title, group and metadata without that cue.

Build the primary action through to its destination or visible result. Open the page in the project's browser or local preview tool and inspect the same content at narrow and wide widths. If the default preview is unavailable, look for a local browser that can capture the page at a specified window size. Follow the action by keyboard, try a long title and check that the control still has room when it wraps. If a narrow list loses context, keep each value beside its label or entry as the columns collapse. Report the viewport and observed result, or identify the rendering check that remains open.

## Try it

Design a quiet reading index with a strong typographic hierarchy.

**Expected result.** A functioning view with consistent hierarchy, states and a rationale tied to the reading task.

A quiet reading index can emphasize the title using size and spacing while keeping metadata subordinate. Stress the chosen hierarchy with the longest supplied title.

**Limit.** Asset rights and production performance need verification in the actual project.
